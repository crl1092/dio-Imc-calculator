# calculadora de imc em Flutter

Essa é uma simples calculadora de Imc feita em Flutter/Dart.

Para rodar esse projeto:

- Certifique-se que tenha o sdk do flutter e um emulador android instalado e configurado ou use seu dispositivo físico conectado via usb (se for usar a segunda opção certifique-se também se a depuração por usb está habilitada nas opções de desenvolvedor no android);
- Clone o projeto com:
```
  git clone https://github.com/crl1092/dio-Imc-calculator.git 
```
- Após clonado , entre na pasta do projeto e execute o comando a seguir para baixar suas dependências:
```
  flutter pub get
```
- Abra o arquivo localizado em `lib/main.dart` e execute o comando a seguir para rodar o projeto em seu emuladou ou celular físico:
```
  flutter run
```
